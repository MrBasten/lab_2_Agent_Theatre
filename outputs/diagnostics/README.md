# Диагностические результаты

`local_missing_direction.events.jsonl` — настоящий неуспешный эксперимент Qwen3-1.7B до доработки механизма ремарок. На втором действии Марк дважды вернул `speak` с текстом, но без `stage_direction`. Валидатор остановил выполнение; никаких тестовых реплик вместо ответа модели не подставлялось.

Доработка: отсутствующий жест создаёт отдельным запросом настоящий рассказчик, а исходная реплика актёра сохраняется. В `stage_direction_source` записывается `model` либо `narrator`.

`../local/` — завершённая отрицательная базовая проверка Qwen3-1.7B: технический протокол выполнен, но повторяемость и смешение ролей не удовлетворяют художественной задаче. Не выдавать этот текст за успешную финальную пьесу.

Эти артефакты нужны для обсуждения ограничений малой модели и проверки обоснованности исправлений. Основной запуск для сдачи — `live` с облачными ролями и локальным Эхом, после подключения ключей.

`local_4b_wddm_paging_2026-11-04.*` и `local_4b_load_metadata.json` — диагностика выхода BF16-процесса в shared RAM Windows. После этого включены NF4 и освобождение CUDA-кеша между запросами.

`local_4b_nf4_duplicate_2026-11-04.events.jsonl` и `.review.json` — настоящий NF4-эксперимент с семью принятыми репликами из девяти, остановленный из-за повторного текста Марка после одной попытки исправления. Полный `play.json` не создан.

`read_file_compatibility_recheck.json` — отдельное повторное исполнение восьми отвергнутых аргументов чтения после исправления интерфейса. Оно подтверждает работу инструмента с согласованными ID и именем файла; новую пьесу этот тест не генерирует.
